# Dependencies

Tools and resources referenced from this vault.

- [Neural-Visualizer](https://github.com/PeakScripter/Neural-Visualizer) — interactive web app to visualize NN architectures (ANN, CNN, RNN, LSTM, GAN, Transformer, Diffusion).
- [DeepWiki](https://deepwiki.com/) — git repo visualization / auto-generated documentation for GitHub repos.
- [Gitingest](https://gitingest.com/) — turns any git repo into an LLM-ready text digest (swap `github.com` → `gitingest.com` in a repo URL).
